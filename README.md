# LLD — Java Concurrency & Low Level Design Practice

A collection of Java implementations covering core concurrency concepts, multithreading patterns, and low-level design problems.

## 📂 Contents

| Module | Description |
|---|---|
| [concurrency1](https://github.com/Sravan2808/LLD/tree/main/concurrency1) | Basic concurrency concepts and examples |
| [concurrency2](https://github.com/Sravan2808/LLD/tree/main/concurrency2) | Advanced concurrency concepts and examples |
| [executorservice](https://github.com/Sravan2808/LLD/tree/main/executorservice) | Java ExecutorService usage and thread pool management |
| [generics](https://github.com/Sravan2808/LLD/tree/main/generics) | Generics in Java |
| [multithreadedmergesort](https://github.com/Sravan2808/LLD/tree/main/multithreadedmergesort) | Multithreaded implementation of merge sort |
| [producerconsumer](https://github.com/Sravan2808/LLD/tree/main/producerconsumer) | Classic producer-consumer problem |
| [producerconsumersemaphore](https://github.com/Sravan2808/LLD/tree/main/producerconsumersemaphore) | Producer-consumer using semaphores |
| [producerconsumersynchronized](https://github.com/Sravan2808/LLD/tree/main/producerconsumersynchronized) | Producer-consumer using `synchronized` blocks |
| [synchronization](https://github.com/Sravan2808/LLD/tree/main/synchronization) | Thread synchronization techniques |

## 🛠️ Tech Stack

- **Language:** Java

## 🚀 Getting Started

```bash
git clone https://github.com/Sravan2808/LLD.git
cd LLD
```

Navigate into any module folder and compile/run the Java files individually:

```bash
javac Main.java
java Main
```

## 📌 Purpose

This repo serves as a practice ground for Low Level Design (LLD) and Java concurrency concepts — useful for interview prep and strengthening multithreading fundamentals.
